## Projects

### 1. Basic Rule-Based Chatbot
📁 `CodeAlpha_Chatbot/`

A simple rule-based chatbot that responds to predefined user inputs using conditional matching, simulating a basic scripted conversation.

**Highlights:**
- Responds to greetings and small talk
- Follows a simple scripted conversation flow
- Case-insensitive input handling

➡️ [Read the full README](./CodeAlpha_Chatbot/README.md)

### 2. Hangman Game
📁 `CodeAlpha_Hangman/`

A command-line Hangman game where the program randomly selects a word and the player guesses it letter by letter before running out of attempts.

**Highlights:**
- Randomized word selection
- Tracks guessed letters and remaining attempts
- Win/loss messages with a max of 6 wrong guesses

➡️ [Read the full README](./CodeAlpha_Hangman/README.md)

## Getting Started

### Prerequisites
- Python 3.14.2 installed on your system

### Installation

1. Clone this repository:
   ```bash
   git clone https://github.com/mjcodes-77/codealpha_tasks.git
   cd codealpha_tasks
   ```
2. Navigate into whichever project you want to run:
   ```bash
   cd CodeAlpha_Chatbot
   python chatbot.py
   ```
   or
   ```bash
   cd CodeAlpha_Hangman
   python hangman.py
   ```
